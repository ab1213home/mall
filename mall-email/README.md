# Jiang Mall Email Module

## 介绍
邮件模块

## 开发工具
IntelliJ IDEA 2024.2.3 (Ultimate Edition)

Navicat Premium Lite 版本17.1.5(简体中文)

## 技术栈

- **后端**：Spring Boot 3.3.4 (Oracle OpenJDK 17.0.11)
- **数据库**：MySQL 8.0.36 (MySQL Community Server) 
- **缓存**：Redis 6.2.16
- **构建工具**：Maven 3.8.4
- **版本控制**：Git

#### 后端

1. 使用[mybatis-plus](https://github.com/baomidou/mybatis-plus "v3.5.8")实现数据库操作

2. 使用[mysql-connector-j](https://github.com/mysql/mysql-connector-j "v8.3.0")实现数据库连接

3. 使用[jakarta-mail](https://github.com/jakartaee/mail-api "v2.0.1")实现邮件发送

4. 使用[redis](https://github.com/redis/redis "v6.2.16")]实现缓存

5. 使用[pool2](https://github.com/j-easy/easy-pool "v2.12.0")实现Redis线程池

6. 使用[javax.servlet-api](https://github.com/javax-servlet/servlet-api "v4.0.1")实现Servlet
