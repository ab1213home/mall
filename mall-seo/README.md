# Jiang Mall Common Module

## 介绍
公共模块

## 开发工具
IntelliJ IDEA 2024.2.3 (Ultimate Edition)

## 技术栈

- **后端**：Spring Boot 3.3.4 (Oracle OpenJDK 17.0.11)
- **缓存**：Redis 6.2.16
- **构建工具**：Maven 3.8.4
- **版本控制**：Git

#### 后端

1. **SEO 工具支持**  
   使用 [sitemapgen4j](https://github.com/dfabulich/sitemapgen4j)  
   - 功能：提供站点地图（Sitemap）生成工具，帮助搜索引擎更好地抓取和索引网站内容，提升 SEO 效果。

2. **商品模块支持**  
   使用 [mall-product](../mall-product/README.md)  
   - 功能：集成项目的商品模块，提供商品相关的数据模型、服务和接口支持，适用于 SEO 中涉及商品信息的场景。

3. **公共模块支持**  
   使用 [mall-common](../mall-common/README.md)  
   - 功能：集成项目的公共模块，提供通用工具类、配置和基础功能支持，确保代码复用性和一致性。
